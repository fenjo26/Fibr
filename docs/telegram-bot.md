# Telegram-бот и Mini App

Бот — точка входа для пользователей: он выдаёт кнопку Mini App, регистрирует
пользователей и отвечает командами. Mini App — интерфейс пользователя
(свои устройства, QR, статистика). Админку бот не заменяет.

## Как работает бот

- Бот общается с Telegram по **long polling** — исходящие HTTPS-соединения
  к api.telegram.org. Публичный вебхук и открытые дополнительные порты
  не нужны.
- Запускается вместе с сервером, если задан `FIBR_TELEGRAM_BOT_TOKEN` в
  `/opt/fibr/install/.env`. Смена настроек — правка `.env` и
  `docker compose -f /opt/fibr/install/docker-compose.yml up -d`.
- **Любое сообщение** боту (в том числе неизвестная команда) создаёт или
  обновляет запись пользователя в базе: Telegram ID, @username (или имя),
  роль. Сообщения от отключённых пользователей молча игнорируются.
- Язык ответов выбирается по `language_code` отправителя: `ru` для
  русского/украинского/белорусского, иначе английский.

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | все | приветствие и inline-кнопка «Открыть Fibr» (запуск Mini App) |
| `/help` | все | список команд |
| `/stats` | только админы | сводка: пользователи, устройства, онлайн, суммарный трафик, текущая скорость туннеля |
| `/id` | все | показывает ваш числовой Telegram ID |

`/id` — самый быстрый способ узнать свой ID для
`FIBR_ADMIN_TELEGRAM_IDS`: запустите бота с токеном, напишите ему `/id`,
скопируйте число в `.env` и перезапустите контейнеры.

## Роли и FIBR_ADMIN_TELEGRAM_IDS

Роли две: `user` и `admin`.

- Список `FIBR_ADMIN_TELEGRAM_IDS` (числовые ID через запятую) задаёт, кто
  автоматически становится админом: при первом сообщении такой пользователь
  создаётся сразу с ролью `admin`, а существующему роль повышается при
  следующем сообщении боту.
- Права админа в боте — это доступ к `/stats`. Полные права администратора
  в веб-панели даёт **админ-токен** (`FIBR_ADMIN_TOKEN`), а не Telegram ID;
  `FIBR_ADMIN_TELEGRAM_IDS` удобно совмещать с ним, но это отдельные
  механизмы.
- Роль хранится в базе, менять её можно и в админке (кнопки «Сделать
  админом» / «Сделать пользователем»).

## Как устроен Mini App

Mini App — это веб-страница `https://<домен>/miniapp/`, открытая внутри
Telegram. Без бота она не работает.

**Вход.** При открытии Telegram передаёт странице подписанные данные
пользователя — `initData`. Mini App отправляет их на
`POST /api/auth/telegram`, сервер проверяет подпись по официальному
алгоритму Telegram (HMAC-SHA256 c ключом, выведенным из токена бота) и
свежесть (`auth_date` не старше 24 часов). Взамен выдаётся сессионный
токен `uid.подпись` (HMAC по `FIBR_SECRET`, живёт 30 дней), который Mini
App кладёт в sessionStorage и шлёт как `Authorization: Bearer <token>` во
все запросы `/api/me/*`. Подписаться за чужого пользователя нельзя: нет
данных, подписанных токеном бота, — нет сессии.

**Возможности.** В Mini App пользователь видит свои устройства (адрес,
онлайн/офлайн, время последнего handshake, трафик ↓/↑, счётчик
«сколько устройств / лимит»), добавляет новые (после добавления сразу
открывается QR), показывает QR и текст конфига, удаляет устройства.
Список обновляется автоматически каждые 20 секунд. Отключённый
администратором пользователь получает экран «аккаунт отключён».

**Почему обязателен HTTPS-домен.** Это ограничение платформы Telegram:
Mini App открываются только по https-ссылкам, и кнопки Web App в ботах
принимают https-URL. Поэтому в режиме `--dev` (домен `localhost`) бот
пишет приветствие без кнопки, а Mini App недоступен. Fibr выдаёт TLS
через Caddy (Let's Encrypt) автоматически — нужен только домен с
A-записью на сервер.

## Настройка: краткий чек-лист

1. `@BotFather` → `/newbot` → токен → `FIBR_TELEGRAM_BOT_TOKEN` в
   `/opt/fibr/install/.env`.
2. Узнать свой ID (`/id` у бота после старта или `@userinfobot`) →
   `FIBR_ADMIN_TELEGRAM_IDS`.
3. `docker compose -f /opt/fibr/install/docker-compose.yml up -d`.
4. BotFather: `/mybots` → бот → Bot Settings → **Menu Button** →
   `https://<домен>/miniapp/` — теперь Mini App открывается кнопкой
   меню рядом с полем ввода.
5. Открыть бота → Start → «Открыть Fibr».
