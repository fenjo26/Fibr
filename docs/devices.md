# Подключение устройств

Каждое устройство в Fibr — это отдельный ключ (пир WireGuard или ссылка
VLESS) со своим адресом `10.8.0.x`. **Одно устройство = один телефон /
ноутбук / ТВ.** Для каждого гаджета создайте своё устройство — их видно и
можно отключать по одному. Клиент Fibr не обязателен: конфиги совместимы
с официальными WireGuard и AmneziaVPN.

## Быстрый старт: выберите способ

Всё начинается в Telegram: откройте бота Fibr (по ссылке-приглашению) →
**Старт**.

| Способ | Когда удобно | Что сделать |
|---|---|---|
| **Файл в чат** | один телефон, проще всего | напишите боту `/new` (или `/new iPhone`) — придёт файл `.conf`. Нажмите на него → «Открыть в…» → WireGuard / AmneziaVPN / Fibr |
| **QR-код** | настраиваете другой гаджет (ноутбук, второй телефон) | бот → «Открыть Fibr» → добавьте устройство → «QR-код» → в WireGuard/Amnezia/Fibr: «+» → «Из QR-кода» |
| **Файл из Mini App** | конфиг уже создан | у устройства кнопка «Файл в Telegram» — бот пришлёт `.conf` в чат |
| **Код подключения** | приложение Fibr, нет второго экрана | у устройства кнопка «Код» → в Fibr: «Добавить» → «По коду» → вставьте ссылку или код |
| **Вставить / файл** | скопировали конфиг или ссылку | в Fibr: «Добавить» → «Вставить / файл» → «Из буфера» или «Выбрать файл» |
| **Телевизор** | Android TV с приложением Fibr | на ТВ откроется QR → отсканируйте телефоном → выберите устройство. Или в Mini App «📺 Подключить телевизор» → введите код с экрана ТВ |
| **VLESS** | WireGuard блокируют | в Mini App создайте устройство с протоколом Xray → ссылка/QR в v2rayNG, Hiddify, Streisand или AmneziaVPN |

После подключения включите туннель и проверьте любой «мой IP» сайт —
должен показываться IP сервера, а не домашний. В Mini App устройство
станет зелёным «онлайн» в течение минуты.

### Какое приложение поставить

| Платформа | Рекомендуем | Альтернатива |
|---|---|---|
| Android | Fibr (APK у бота: `/app`) или [WireGuard](https://play.google.com/store/apps/details?id=com.wireguard.android) | [AmneziaVPN](https://amnezia.org) |
| iPhone / iPad | [WireGuard](https://apps.apple.com/app/wireguard/id1441195209) | AmneziaVPN |
| Windows / macOS | [WireGuard](https://www.wireguard.com/install/) | AmneziaVPN |
| Android TV | Fibr (APK у бота: `/app`) | WireGuard |
| Apple TV, Smart TV | только через роутер — [routers.md](routers.md) | |

**Где в AmneziaVPN:** экран подключения → «Файл с настройками подключения»
(для `.conf`) или «QR-код». **Где в WireGuard:** «+» → «Создать из QR-кода»
или «Создать из файла или архива».

## Формат конфигурации

Fibr отдаёт стандартный конфиг wg-quick (кнопка «QR-код» или «Конфиг»
в Mini App; «QR» / «Конфиг» / «Скачать .conf» в админке):

```ini
[Interface]
PrivateKey = <приватный ключ устройства>
Address = 10.8.0.2/32
DNS = 1.1.1.1, 1.0.0.1
MTU = 1420

[Peer]
PublicKey = <публичный ключ сервера Fibr>
PresharedKey = <прешаренный ключ>
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint = vpn.example.com:51820
PersistentKeepalive = 25
```

| Поле | Значение |
|---|---|
| `Address` | адрес устройства в туннеле `/32` (выдаётся автоматически) |
| `DNS` | берётся из `FIBR_DNS` на сервере (по умолчанию `1.1.1.1, 1.0.0.1`) |
| `MTU` | 1420 (настраивается через `FIBR_MTU`) |
| `AllowedIPs = 0.0.0.0/0, ::/0` | полный туннель: весь трафик устройства идёт через VPN |
| `Endpoint` | `FIBR_DOMAIN` (или `FIBR_WG_HOST`) и UDP-порт (по умолчанию 51820) |
| `PersistentKeepalive = 25` | держит NAT-привязку открытой (каждые 25 секунд) |

## Android

**Проще всего — файлом, на одном телефоне:**

1. Поставьте Fibr (бот пришлёт APK по команде `/app`), WireGuard или
   AmneziaVPN.
2. Напишите боту `/new Мой телефон` — придёт файл `.conf`.
3. Нажмите на файл → «Открыть в…» → выберите приложение (в Fibr файл
   импортируется сразу; в AmneziaVPN — «Файл с настройками подключения»;
   в WireGuard — «+» → «Импорт из файла»).
4. Включите туннель, разрешите добавление VPN.

**В приложении Fibr** можно и без файла: «Добавить» → «Вставить / файл»
→ «Из буфера» (скопируйте конфиг, ссылку или код) или вкладка «По коду».

**По QR со второго экрана:** Mini App → «QR-код» → в приложении «+» →
«Создать из QR-кода».

## iPhone / iPad

1. Установите [WireGuard](https://apps.apple.com/app/wireguard/id1441195209)
   или AmneziaVPN из App Store.
2. Напишите боту `/new iPhone` — придёт файл `.conf`.
3. Нажмите на файл → «Поделиться» → WireGuard (или AmneziaVPN →
   «Файл с настройками подключения») → разрешите добавление VPN-профиля.
4. Включите туннель.

Есть второй экран — можно по QR: Mini App → «QR-код» → в WireGuard **+**
→ **Create from QR code**.

## Windows

1. Установите [WireGuard для Windows](https://download.wireguard.com/windows/).
2. Получите файл: напишите боту `/new Ноутбук` в Telegram Desktop — файл
   `.conf` придёт в чат, сохраните его. Либо в Mini App «Конфиг» →
   «Скачать .conf» / «Файл в Telegram».
3. В WireGuard: **Import tunnel(s) from file** → выберите файл → Activate.

Windows-клиент не умеет сканировать QR — используйте импорт файла.

## macOS

1. Установите [WireGuard для macOS](https://itunes.apple.com/us/app/wireguard/id1451685025)
   из App Store.
2. В админке скачайте `.conf` (или скопируйте текст «Конфига» из Mini App
   в файл).
3. В WireGuard: **File** → **Import tunnel(s) from file…** → выберите
   файл → включите туннель. Или **Add Tunnel** → **Create from QR code**
   и отсканируйте QR с телефона/второго окна.

## Linux

**wg-quick** (конфиг в `/etc/wireguard/`):

```bash
# сохраните текст конфига (кнопка «Конфиг» в Mini App / админке) в файл:
sudo nano /etc/wireguard/fibr.conf
sudo chmod 600 /etc/wireguard/fibr.conf

sudo wg-quick up fibr          # включить
sudo wg-quick down fibr        # выключить
sudo systemctl enable wg-quick@fibr   # автозапуск
```

**NetworkManager** (GNOME и др.): настройки сети → VPN → «Импорт из файла…»
→ выберите `.conf`, скачанный из админки.

## Android TV

С пульта неудобно набирать ссылки и коды, поэтому ТВ подключается
**с телефона**:

1. Поставьте на ТВ приложение Fibr одним из способов:
   - **Через флешку:** скачайте APK-файл (`https://ваш-домен/tv.apk` или бот → `/app`), скопируйте на флешку, вставьте в телевизор и установите через любой файловый менеджер.
   - **Без флешки — через Downloader (самый быстрый способ):** установите на ТВ из Google Play приложение **Downloader by AFTVnews**, введите в адресную строку `ваш-домен/tv.apk` и нажмите **Go** — приложение скачается и сразу начнёт установку.
   - **Без флешки — с телефона («Send Files to TV»):** установите приложение **Send Files to TV** на телефон и ТВ, скачайте APK на телефон и перешлите на телевизор по домашней сети (либо через `adb install`).
2. Откройте Fibr на ТВ. Один раз введите адрес сервера (если его там ещё
   нет) — на экране появятся **QR-код** и короткий **код**.
3. Отсканируйте QR камерой телефона → откроется бот Fibr → «Открыть
   Fibr» → выберите «Новое устройство для ТВ» (или отдайте ТВ уже
   созданное WG-устройство).
   *Без камеры:* Mini App → «📺 Подключить телевизор» → введите код с
   экрана ТВ.
4. Телевизор подключится сам через 2–3 секунды.

Запасной вариант без телефона — вкладка с кодом подключения на том же
экране (код берётся в Mini App кнопкой «Код» у устройства).

## Apple TV и обычные Smart TV

На этих платформах нет клиента WireGuard, а настроить туннель вручную
нельзя. Единственный рабочий вариант — **завести VPN на роутере**:
тогда все устройства за ним (TV, приставки, консоли, умный дом) ходят
в интернет через Fibr автоматически.

Создайте в Fibr отдельное устройство (например, «Роутер домой») и
настройте туннель на роутере по инструкции: [routers.md](routers.md).

## Полезно знать

- **Одно устройство = один пир.** Не ставьте один файл/QR на два гаджета:
  WireGuard пускает с одного ключа только одно устройство одновременно —
  связь будет рваться у обоих. Для каждого гаджета — своё устройство
  (`/new` в боте или «Добавить» в Mini App). Ссылки VLESS ограничены
  лимитером: с одной ссылки из многих сетей сразу — ссылка временно
  отключается ([xray.md](xray.md)).
- **Лимит устройств**: глобальный дефолт — `FIBR_MAX_DEVICES` (по умолчанию
  10), но суперадмин и админ-реселлер могут ставить персональный лимит
  каждому пользователю («пакет на 5 устройств»). Эффективный лимит юзера —
  минимум его собственного и лимита его админа (как сроки в
  [billing.md](billing.md)); админ не может выдать юзеру больше, чем имеет
  сам. В Mini App лимит виден как «устройств 3 / 5».
- **Отключение** устройства в админке удаляет пира из конфигурации сервера —
  сеанс рвётся сразу; повторное включение восстанавливает доступ.
- **«Онлайн»** = handshake за последние 3 минуты; статистика трафика
  собирается каждые 30 секунд (`FIBR_STATS_INTERVAL`).
