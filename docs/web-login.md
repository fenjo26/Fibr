# Веб-кабинет: вход без Telegram

Главная дверь для пользователя — веб-кабинет `https://<домен>/cabinet/`.
Telegram — только дополнительный способ входа.

## Как человек попадает в кабинет

1. **Ссылка-приглашение** (`/cabinet/?invite=КОД`, админка → «Пригласить»
   или `/invite` в боте). Открыл в любом браузере — аккаунт создан сразу,
   без Telegram и паролей. Кабинет показывает **ссылку для входа**
   (`/cabinet/#k=КОД`) и запоминает человека в этом браузере.
2. **Код для входа от админа** — админка → пользователь → ✏ →
   «🔑 Код для входа». Для уже существующих пользователей; повторная
   выдача отменяет прежний код.
3. **Логин и пароль** — человек сам задаёт их в кабинете (раздел «Логин и
   пароль») и дальше входит ими с любого устройства. Пароль хранится
   только хешем (PBKDF2-SHA256), после 10 неудачных попыток вход по этому
   логину блокируется на 15 минут.
4. **Telegram** — кнопка «Войти через Telegram» (нужен `/setdomain` в
   @BotFather) или Mini App в боте.

Ссылка для входа работает и в приложении Fibr: «Ключ доступа» → вставить
ссылку целиком — адрес сервера и ключ заполнятся сами.

## API

| Метод | Что делает |
|---|---|
| `POST /api/auth/invite {invite_code}` | регистрация по инвайту → `{token, user, key, login_link}` |
| `POST /api/auth/key {key}` | вход по коду / ссылке для входа |
| `POST /api/auth/password {login, password}` | вход по логину и паролю |
| `POST /api/me/password {login, password}` | задать / сменить свои логин и пароль |
| `POST /api/admin/users/{id}/access-key` | админ выдаёт код для входа |
