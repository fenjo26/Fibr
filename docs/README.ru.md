## Архитектура системы

```
                      ┌──────────────────────────── VPS ────────────────────────────┐
 Telegram ⇄ бот (long polling)                                      │
 Mini App ⇄ Caddy ──TLS── /api/* ──► fibr-api (Go) ── wgctrl ──► wg0 (kernel)
 (HTTPS)         ├─ /admin/*  статика      │                     │ iptables NAT
                 ├─ /cabinet/* статика     ├── SQLite (/data)    ▼
                 └─ /shared/*  токены      └── /data/xray/config.json → xray (VLESS+Reality)
                                                               Интернет
```
