# Начало работы

Путь от нуля до работающего VPN: VPS → домен → установка → админка →
Telegram-бот → первое устройство. Занимает около 15 минут.

## 1. Купите VPS

Требования:

- **ОС:** Ubuntu 22.04+ или Debian 12 (установщик проверяет ОС; на других
  дистрибутивах предупредит, что система непротестирована, и предположит
  Debian-подобную).
- **Ресурсы:** 1 vCPU / 1 GB RAM / 10 GB диска достаточно — Fibr работает
  в двух контейнерах (Go-сервер + Caddy), состояние хранит в SQLite.
- **Доступ:** root или sudo. Установщик сам перезапускается через `sudo`,
  если запущен не от root.
- **Сеть:** открытые порты 80/tcp и 443/tcp (TLS и веб-панели) и один UDP-порт
  для WireGuard (по умолчанию 51820). Если на сервере активен `ufw`,
  установщик откроет их сам.

## 2. Направьте домен

Создайте **A-запись**, указывающую на публичный IP сервера, например:

```
vpn.example.com.  A  203.0.113.10
```

Если домен на Cloudflare — переключите запись в режим **DNS-only**
(серое облако, проксирование выключено). Установщик сверяет, что домен
резолвится именно в публичный IP сервера: за прокси Cloudflare проверка
закончится ошибкой с подсказкой переключить запись в DNS-only. Обходной
путь — `--skip-dns-check` — нужен только если вы понимаете, что делаете.

Дождитесь, пока запись расклеится (обычно минуты): `dig +short vpn.example.com`
должен вернуть IP сервера.

## 3. Установите Fibr одной командой

На чистом сервере, от root:

```bash
curl -fsSL https://raw.githubusercontent.com/fenjo26/Fibr/main/install/install.sh \
  | bash -s -- --domain vpn.example.com
```

Или из чек-аута репозитория:

```bash
bash install/install.sh --domain vpn.example.com
```

Что делает установщик:

1. Ставит Docker (через `get.docker.com`), если его нет; требует плагин
   docker compose.
2. Клонирует репозиторий в `/opt/fibr` (или переиспользует существующий /
   копирует из чек-аута, откуда запущен).
3. Проверяет DNS: домен должен резолвиться в публичный IP сервера.
4. Копирует `/opt/fibr/install/.env.example` в `/opt/fibr/install/.env`
   и генерирует секреты: `FIBR_ADMIN_TOKEN` и `FIBR_SECRET`
   (файл получает права `600`).
5. Открывает порты 80/tcp, 443/tcp и UDP-порт WireGuard, если активен `ufw`.
6. Собирает и запускает контейнеры (`docker compose up -d --build`) и ждёт
   готовности API (healthcheck `/api/health`).

В конце установщик печатает адрес админки, админ-токен, адрес Mini App и
UDP-порт WireGuard. Сохраните этот вывод.

### Опции установщика

| Опция | Назначение |
|---|---|
| `--domain DOMAIN` | публичный домен с A-записью на этот сервер (обязательна, если не `--dev`) |
| `--port PORT` | UDP-порт WireGuard (по умолчанию 51820) |
| `--dev` | локальный режим: домен `localhost`, HTTP без TLS, без проверки DNS |
| `--skip-dns-check` | ставить даже при непройденной DNS-проверке (например, за NAT) |
| `--force` | перегенерировать секреты в существующем `.env` |
| `--uninstall` | остановить и удалить контейнеры (данные и тома остаются) |
| `--purge` | с `--uninstall`: удалить всё, включая данные (`docker compose down -v` и удаление `/opt/fibr`) |

При повторном запуске на существующей установке `.env` сохраняется
(секреты не перегенерируются), но указанные `--domain`/`--port` в него
дописываются.

## 4. Первый вход в админку

Откройте `https://vpn.example.com/admin/`. В поле входа вставьте админ-токен
из `/opt/fibr/install/.env`:

```bash
grep FIBR_ADMIN_TOKEN /opt/fibr/install/.env
```

В админке доступны:

- **Дашборд** — кто онлайн, число пользователей и устройств, суммарный
  трафик, текущая скорость туннеля, параметры сервера (публичный ключ,
  порт, endpoint, подсеть, DNS, MTU) и активные устройства.
- **Пользователи** — создание (имя, необязательный Telegram ID, роль),
  выдача устройства вручную, отключение/включение, смена роли, удаление.
- **Устройства** — все устройства: QR, конфиг, кнопка «Скачать .conf»,
  включение/отключение (отключение рвёт сеанс), удаление.

Токен запоминается в localStorage браузера; «Выйти» его удаляет.

## 5. Подключите Telegram-бота и Mini App

Бот нужен для входа пользователей: Mini App авторизуется через Telegram
(`initData`), а бот — точка входа с кнопкой приложения.

1. Откройте [@BotFather](https://t.me/BotFather) → команда `/newbot` →
   задайте имя и username бота → скопируйте токен вида
   `1234567:AA...`.
2. Узнайте свой числовой Telegram ID — одним из способов:
   - напишите `/id` вашему боту Fibr после его запуска (шаг 3 ниже);
   - или откройте [@userinfobot](https://t.me/userinfobot) — он покажет `Id`.
3. Подключите бота **той же командой установки** — файлы править руками
   не нужно (установщик безопасно обновит уже работающий сервер):

   ```bash
   curl -fsSL https://raw.githubusercontent.com/fenjo26/Fibr/main/install/install.sh \
     | bash -s -- --domain vpn.example.com \
         --bot-token 1234567:AA... \
         --admin-tg 12345678
   ```

   `--admin-tg` — список ID через запятую; перечисленные пользователи при
   первом сообщении боту автоматически получают роль суперадмина (и команду
   `/stats`). Подробнее — в [telegram-bot.md](telegram-bot.md).
4. Вернитесь в BotFather: `/mybots` → ваш бот → **Bot Settings** →
   **Menu Button** → укажите `https://vpn.example.com/miniapp/`.
5. Откройте бота в Telegram → **Start** → кнопка «Открыть Fibr».

Mini App работает только по HTTPS-домену — это ограничение платформы
Telegram (кнопки Web App требуют https-URL), поэтому шаг недоступен в
режиме `--dev`.

## 6. Первое устройство

Самый быстрый путь: напишите боту `/new Мой телефон` — придёт файл
`.conf`. Нажмите на него → «Открыть в…» → WireGuard / AmneziaVPN / Fibr →
включите туннель. Через минуту устройство станет «онлайн» в Mini App и
админке.

Другие способы — QR-код, код подключения, «Файл в Telegram», телевизор с
телефона, VLESS — в таблице «Быстрый старт» в [devices.md](devices.md).
Лимит устройств на пользователя задаётся `FIBR_MAX_DEVICES` (по
умолчанию 10) или персонально в админке.

Роутеры, Apple TV и Smart TV — [routers.md](routers.md).

## Что дальше

- Пригласите пользователей: они пишут боту `/start` и сами добавляют
  устройства — админ их не создаёт.
- Логи: `docker compose -f /opt/fibr/install/docker-compose.yml logs -f fibr`.
- Обновление, смена порта, перенос сервера — [faq.md](faq.md).
